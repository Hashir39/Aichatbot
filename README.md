# AI Chatbot

A full-stack AI chatbot application with user authentication, chat history, and image support.

Powered by Google Generative AI, with persistent chat storage and a modern React frontend.

## Features

- **AI Chat** — Conversations powered by Google Gemini
- **User Authentication** — Secure auth with Clerk
- **Chat History** — Persistent chats stored in MongoDB
- **Image Support** — Upload and send images in chats (ImageKit)
- **Multiple Chats** — Create and switch between conversations
- **Modern UI** — React + Vite frontend

## Tech Stack

### Frontend
- React 19 + Vite
- Clerk (authentication)
- Google Generative AI SDK
- ImageKit React
- TanStack Query
- React Router
- React Type Animation

### Backend
- Node.js + Express
- MongoDB + Mongoose
- Clerk SDK (auth middleware)
- ImageKit (image uploads)
